GUTS Scheduler - Privacy policy

Last updated: 30 October 2026

Who uses it

GUTS Scheduler is used only by one private household, on its own computer. It is not offered to the public.

What Google data it uses

With the account owner's permission, it reads, creates, changes and deletes events on that owner's Google Calendar (permissions calendar and calendar.events). It does not request or use any other Google data.

How the data is used

Calendar data is used only to show the household its schedule and to add or change events the household asks for. It is not used for advertising, profiling or training AI models.

Storage and sharing

The sign-in token and any calendar data are kept on the household's own computer. Nothing is sold, and nothing is shared with anyone outside the household. Data goes only to Google, to carry out the calendar changes asked for.

Google API Services User Data Policy

GUTS Scheduler's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account owner can remove GUTS Scheduler's access at any time at myaccount.google.com/permissions. The locally stored token is then deleted.
